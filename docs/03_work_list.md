## Шаг 1. RP Core (0.4.x → 0.5.0)
Одной версией — всё, что нужно остальным, чтобы потом не пересобирать всех по нескольку раз.

1. **Событие восстановления выносливости** `StaminaRestoredEvent(player, amount)` рядом с `ExertionEvent`. Посылает
   Stamina, слушает Culinary (калории за отдых).
2. **Прямой опыт навыка:** `RpCoreAPI.grantXp(player, skill, xp)` — ровно N опыта. Нынешний `practice` для Силы и
   Телосложения умножается на «опыт за 100 выносливости», а Sports даёт опыт за повтор.
3. **Розетка тела `BodyProvider`**, новые вызовы (по умолчанию «не умею»):
   - `bruise(player, part, severity)` — ушиб части тела;
   - `strain(player, part, stage)` — боль в мышцах → растяжение → надрыв;
   - `canExert(player, part)` — можно ли нагружать (перелом, сильная боль);
   - `learningFactor(player)` — насколько хорошо учится, 0–1 (боль).
4. **Части тела в `RpIds`:** `head`, `chest`, `abdomen`, `left_arm`, `right_arm`, `left_leg`, `right_leg`, `left_foot`,
   `right_foot` — чтобы Sports не знал внутренностей Medicine.
5. **Розетка питания `NutritionProvider`:**
   - `thirstStage(player)` — сейчас есть только `hydration`;
   - `consumeNutrient(player, id, amount)` — расход белка на тренировке. Чтение белка уже есть: `nutrient(player, "protein")`.
6. **Новые черты в `RpIds`** для Sports: `agile`, `clumsy`, `unlucky`, `melee_fighter`, `strongman`, `wimp`, `enduring`,
   `weakling`, `athlete`, `turtle`.

### 2б. RP Stamina
1. **Убрать еду из расходников:** мёд, золотая морковь, ягоды, печенье.
2. **Вода** — +30, с привыканием (сейчас 120 + 12 — стояло для теста).
3. **Стимуляторы** — новый вид расходника: **множитель** восстановления на время, потом откат.

   - стадии: ×0,75 / ×0,5 / ×0,25;

6. **Посылать `StaminaRestoredEvent`** при любом восстановлении.
7. **Без Culinary** — медленная пассивная трата ванильного голода (сейчас её нет совсем).
